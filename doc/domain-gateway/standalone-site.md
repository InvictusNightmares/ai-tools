# 独立静态网站部署记录

2026-11-18，独立静态网站从最初的主机迁入一台已有公网网关的主机。两个域名共用公网地址。访问网站域名会打开静态首页，访问原管理域名仍会进入原面板。首页内容由新主机本地提供。

## 现行部署

- 在域名控制台编辑已有的根记录（`@ A`），将唯一目标替换为现有公网网关的 IPv4，TTL 沿用一小时。
- Nginx 在 TLS 握手时按精确域名（SNI）分流。网站有独立的回环监听、证书和静态文件目录。原管理域名和默认代理继续使用各自原有的入口。网关在配置校验通过后平滑重载。
- 网站使用现有 ACME 账户，经公网 HTTP-01 验证签发独立域名证书。私钥只对所有者可读，位于网页目录之外。原有宿主机定时器负责续期，新证书安装后会先校验 Nginx 配置再重载网关。
- 项目保留了[静态站点 Nginx 模板](../../script/domain-gateway/templates/standalone-nginx.conf.template)和[首页模板](../../script/domain-gateway/templates/standalone-index.html.template)。实际参数、渲染文件、部署脚本和现场检查结果存放在 Git 忽略的私有目录中。

重建网关时，在现有 `map $ssl_preread_server_name $web_backend` 中合入下面这行，两个值分别对应站点模板里的 `SITE_DOMAIN` 和 `SITE_TLS_PORT`。私有参数中的端口必须与现有监听错开。合入后运行 `nginx -t` 并平滑重载，再按两个域名分别打开首页和面板登录页。

```nginx
<SITE_DOMAIN> 127.0.0.1:<SITE_TLS_PORT>;
```

## 首次部署记录

首次部署使用独立主机，从 Debian 12 的签名软件源安装 Caddy 并启用 systemd 服务。配置校验通过，配置及首页的摘要与本地渲染结果一致。源站 HTTP 返回 `308` 跳转至同域 HTTPS，当时的公共 DNS 查询也返回了预期地址。[首次部署的 Caddy 模板](../../script/domain-gateway/templates/standalone.Caddyfile.template)

首次部署的公网 HTTP 返回 `403`，页面引用了接入商的备案拦截说明。公网 HTTPS 握手被重置，原主机当时也未取得可信证书。签发日志分别记录了共享父域的签发额度限制和备用签发机构的 DNS 查询超时。

原主机按用户先前的选择保留当时的网站配置。
