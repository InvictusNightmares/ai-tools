# 鹈鹕骑单车 · 实时 3D 复刻

参考页面：[Pelican on a Bike](https://claude-opus-5-5.riba2534.cn/)，采集于 2026-09-23。

这是可独立运行的静态网页项目。保留了参考页的程序化海岸、鹈鹕与单车、海浪、昼夜循环、相机、合成声音、抓鱼、成就和参数面板。页面运行所需的 Three.js r186 与场景代码包含在本地脚本中，不需要在线加载模型、贴图或其他依赖。

## 预览

```bash
cd /Users/invictus/Github/ai-tools/effects/08-pelican-bike
python3 -m http.server 8767 --bind 127.0.0.1
```

打开 [http://127.0.0.1:8767/](http://127.0.0.1:8767/)。需要支持 WebGL 的浏览器。项目使用相对路径，可以作为静态目录部署。

## 操作

- 点击「开始骑行」或「静音进入」。顶部可切换自由环绕、追随、侧面跟拍、电影运镜和鹈鹕视角。
- `W` / `S` 加减速，`A` / `D` 变道，空格跳跃，`T` 放手特技，`B` 按铃，`H` 鹈鹕叫，`C` 切换镜头，`N` 快进三小时。
- 右上角可截图、切换音乐、全屏、打开参数面板和帮助。右下角时间轴可调整时刻。
