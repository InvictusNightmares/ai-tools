- 布局与间距：保留 vmin 排版、侧边纵向导航、底部色卡、摄影控件及竖屏整体旋转逻辑。
- 色彩：保留原始车漆参数、材质、灯光、反射、HDR、橙色选中标记和透明背景。
- 图像与素材：47 个素材通过 SHA-256 与大小核对，模型轮廓、纹理、图标和产品标志使用公开页面实际资源。
- 文案：保留五个章节的中文内容；只删除页面作者信息及截图推广信息。素材来源与库许可在文档中保留。

## 修正过程

1. 源码拆分阶段修正了跨模块导出和 Vite 依赖预构建重载问题。这些在视觉验收之前解决，不计作设计比较通过的证据。
2. [P1，已解决] 自定义滑杆在 JSX 还原时，`rN` 被识别成普通 HTML 标签；嵌套的动态 JSX 调用也未完全转换。实际点击发现滑杆没有有效尺寸。将其还原为 `AlphaControl` / `SliderPointer` 组件，并把残留 jsx-runtime 调用转换为 JSX。
3. 修正后重新运行，五个滑杆均为 176 × 5 CSS px 的实际控件；逐个点击后，五个滑块的位置均变为 50%，车辆颜色与材质随之改变。桌面证据见 `local-custom.jpg`，竖屏又执行了一次色相调整。
4. [P3，已解决] React 开发模式提示滑杆中的静态子元素数组缺少 key，已补齐稳定 key。
5. 生产构建重新生成并在独立浏览器标签打开。定制、色相调整、拍照均通过，导出图片 1440 × 900 且成功解码；该标签控制台 error / warn 日志均为空。

## 已知边界

- 未做跨浏览器、真机触摸、长时间运行、低端 GPU 或离线缓存测试。
- 不承诺不同设备/GPU 的 WebGL 输出逐像素一致。
- 界面动画使用固定版本 Framer Motion 11.18.2，原站精确版本未知；源页面未提供 TypeScript、编辑器工程或建模源文件。
- 当前模型不需要 Draco；保留的通用引擎加载器仍有未使用的默认解码器地址，当前资源清单不触发该地址。
