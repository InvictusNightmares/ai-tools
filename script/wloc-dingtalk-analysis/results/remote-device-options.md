# 远程真机方案

这里说的「远程真机」不是某个付费云真机产品，而是：**把一台真实的 iPhone 放在办公室，远程让它完成打卡**。手机的位置是真的在办公室，所以不需要改定位。

> **前提**：如果钉钉账号只允许一台手机在线（实测如此），方案 A 和 B 都不成立——备用机无法登录同一账号。请直接看下面的「单手机路线」。

## 方案 A：轻量版（推荐先试）

```text
办公室：备用 iPhone（登录钉钉、开定位、常充电、不锁屏）
          ↓ 定时
        iOS 快捷指令 / 远程 launch
          ↓
        打开钉钉 → 极速打卡自动完成
```

前提：

- 钉钉组织开启了「极速打卡」，或打开 App 后会自动进入打卡页
- 备用机在办公室、位置权限为「始终」或「使用期间」+ 精确位置
- 手机不锁屏、不断网、保持登录

优点：

- 位置是真实的办公室 GPS/Wi-Fi，**没有 isSimulatedBySoftware 标志**
- 不需要 MITM、不需要伪 AP、不需要改定位
- 手机自己执行快捷指令，不需要家里 Mac 常开

缺点：

- 需要在办公室放一台备用机
- 钉钉账号多设备登录可能互踢，需要先确认
- 极速打卡是否开启取决于组织设置

## 方案 B：完整版（WDA / Appium）

```text
办公室：备用 iPhone + 常开 Mac mini / 旧 Mac
          ↓ USB
        WebDriverAgent（WDA）或 Appium
          ↓ Tailscale / SSH 隧道
家里：Appium 脚本 → 点击钉钉打卡按钮
```

要点：

- WDA 通过 Xcode 安装一次，之后可以在手机上常驻（免费签名 7 天续签，付费开发者账号 1 年）
- 手机必须解锁；WDA 不能绕过锁屏密码
- 建议备用机不设密码、充电时常亮，或使用 Guided Access
- 远程访问用 Tailscale / ZeroTier / SSH 反向隧道，不要把 WDA 的 8100 端口直接暴露公网
- WDA 走 accessibility 注入，部分强风控 App 可能检测自动化；钉钉是否检测需要实测

## 云真机平台（AWS Device Farm、BrowserStack、Testin 等）

不适合日常钉钉打卡：

- 设备在机房，位置不是你的办公室，仍然要改定位
- 机房 IP、陌生设备登录，钉钉风控容易触发验证
- 按分钟计费，不适合每天定时打卡
- 账号隐私风险

这类平台适合 App 测试，不适合长期考勤自动化。

## 单手机路线（你的情况）

只有一台手机、钉钉不允许第二台手机在线时，剩下三条路：

| 方案 | 需要买什么 | 位置来源 | 模拟标志 | 风险 |
|---|---|---|---|---|
| 开发者位置模拟 | 0 元 | locationd 模拟坐标 | `isSimulatedBySoftware` | 中 |
| BSSID 克隆 | OpenWrt 5GHz AP，约 150～400 元 | Apple WLOC 返回办公室坐标 | 无 | 低 |
| 外接 GPS 尾插 | GPS 尾插，约 100～300 元 | 外部定位源 | `isProducedByAccessory` | 低-中 |

建议：

1. **先免费测开发者模拟**：用 pymobiledevice3 把坐标设到办公室，打开钉钉打卡页，看是否接受。如果接受且没有风控提示，就不用买任何硬件。
2. **要长期稳定就上 BSSID**：办公室 AP 的坐标已经在 Apple 库里验证过，一台便宜的 OpenWrt AP 即可，不需要第二台手机。
3. **不想配路由就买尾插**：插在现在的手机上，位置由外部 GPS 提供，不需要第二台手机。

## 对比

| 方案 | 位置来源 | 模拟标志 | 需要硬件 | 风控风险 | 成本 |
|---|---|---|---|---|---|
| 远程真机（轻量版） | 真实办公室 GPS/Wi-Fi | 无 | 备用 iPhone | 最低（但多设备登录） | 低 |
| 远程真机（WDA） | 真实办公室 GPS/Wi-Fi | 无 | 备用 iPhone + Mac | 低-中（自动化可被检测） | 中 |
| BSSID 克隆 | Apple WLOC 返回办公室坐标 | 无 | OpenWrt 5GHz AP | 低 | 低 |
| 开发者模拟 | locationd 模拟坐标 | `isSimulatedBySoftware=true` | 数据线 + Mac | 中 | 0 |
| 外接 GPS 尾插 | 外部 GPS | `isProducedByAccessory=true` | 尾插硬件 | 低-中 | 中 |

## 建议顺序

1. 如果能在办公室放备用机：先试「极速打卡 + 定时打开钉钉」，这是风控最低的。
2. 如果极速打卡不可用：再考虑 WDA/Appium 远程点击。
3. 如果不想放备用机：用已经验证过的 BSSID 克隆（目标 AP 在 Apple 库里有坐标）。
4. 最后才是开发者模拟定位。

## 需要先确认的事

- 钉钉是否允许同一账号在两台手机上同时在线
- 你们组织是否开启了极速打卡
- 备用机能否长期供电、联网、不锁屏
- 办公室是否允许放置无人值守设备
