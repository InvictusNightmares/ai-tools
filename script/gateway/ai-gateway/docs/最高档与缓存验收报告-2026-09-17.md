# 最高档与缓存验收报告（2026-09-17）

本报告关闭P05、P12的真实调用与账单环节。样本为合成输入，候选通过独立固定端点比较；自然Auto另测。所有账单按区域、数字API Key和上游响应UUID唯一关联，HTTP成功、协议完整、token匹配分别检查。

## 最高推理档位

20次固定最高档和两地自然Auto各一次，共22次均完整完成且匹配唯一账单。自然Auto在客户端effort=none时均选Astra xhigh，发送和响应回报均xhigh。客户端参数没有参与选型。

20条effort字段字面相同；两条DeepSeek Responses发送和响应均max，账单reasoning_effort为xhigh。两地实测Sub2API均0.1.161、提交19149ca196eeae4a4482e5299dc6fa4ba0b06c8c，源码元数据解析对非GPT56的max归一化为xhigh。这能解释账单标签，不能证明业务请求在线上被降档；发送、回报和账单原值均保留。DeepSeek Chat未回报effort，保持未知；美西Sol回报gpt-6-sol别名单列。

证据：[原始差异](evidence/2026-09-16-native-media/effort-billing-original-difference.json)、[源码解释与22条对应记录](evidence/2026-09-16-native-media/effort-billing-interpreted.json)。
