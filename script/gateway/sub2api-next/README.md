# 美西 Sub2API 迁移与运行核验

本目录保存官方 Sub2API v0.2.15 的个人账号迁移、历史合并、验收和定向清理工具。脚本固定绑定这次迁移的实例、数据库和证据文件，不是通用安装器，不应直接用于其他服务器。

正式实例使用 `/opt/sub2api-next`，数据库容器为 `sub2api-next-postgres`，库名为 `sub2api_next`。应用不发布宿主机端口，由 `sub2api-next-proxy` 提供 8080；客户继续通过 GPU 4001 访问。旧预览端口 18080 已关闭。

## 代码与私有输入

仓库包含脚本及合成数据测试，不包含真实账号分配 CSV、账号交付文档、密码、管理 Key、客户会话或数据库备份。真实名单和交付文档保留在操作者本地并已加入仓库忽略规则。

服务器上的 `ops/allocation.csv`、迁移状态和验收证据仍由操作者私下提供。代码不根据邮箱或姓名生成客户密码。需要建号或明确执行首次登录验收时，从仓库外的 `/opt/sub2api-next/ops/customer-passwords.json` 读取 JSON 对象，键为登录邮箱，值为操作者提供的密码。可以通过 `SUB2API_CUSTOMER_PASSWORDS_FILE` 指定另一个绝对路径。

密码文件必须是当前操作者所有的普通文件，仅允许所有者访问（例如 0600），不能是符号链接。文件缺失、内容非法或缺少账号密码时直接失败，不猜测密码、不重置线上账号，也不把密码写入输出。不要把真实密码作为命令行参数、示例或仓库文件。

日常配置与历史核对，以及使用现有会话的客户权限核对，不需要此密码文件。更新服务器上的工具时应同步整套 Python 依赖，不能只替换调用方脚本。现有分层布局中，`candidate_*.py` 与 `customer_passwords.py` 位于 `ops/`，服务器切换脚本位于 `ops/cutover/`；私有 RPC 的门户验收会在加载 `ops/` 后导入密码模块。仓库没有自动上传这些文件的部署器。本次密码输入调整尚未部署到服务器；已有线上账号和密码没有改变。

## 当前运行核验

在已部署工具的服务器目录中，使用：

```sh
python3 -B candidate_monitor_v2.py verify
```

默认核对用户角色、授权组、并发、平台额度、历史归属和费用、V2 配置及 V1 删除状态，不执行初始密码登录，不创建测试用户，不修改客户密码。该操作会更新服务器上的验收摘要，不能称为完全无文件写入。

需要核对八个资源组的客户 API 权限时，显式提供 `--sessions /absolute/private/sessions.json`，文件以资源组名映射现有客户会话。该文件同样必须限制权限，验证后清理。`--initial-logins` 仅用于操作者明确选择的首次交付验收，读取上述私密密码文件；它与 `--sessions` 互斥。已有用户改过密码时应停止这类首次登录验收。

## 历史阶段工具的边界

| 工具 | 适用阶段 |
| --- | --- |
| `candidate_ops.py`、`candidate_migrate.py` | 独立预览实例准备、备份、建号及迁移；不能重跑来“刷新”正式配置 |
| `candidate_accept.py` | 历史初次交付验收；没有预览布局保护，不能在正式实例直接运行其中的建号、额度或全员登录步骤 |
| `candidate_portal.py` | 预览期门户配置与旧 V1 阶段；写操作受预览布局检查限制 |
| `candidate_monitor_v2.py configure/delete_legacy` | 预览期 V2 配置和 V1 删除；日常仅使用上述 `verify` |
| `candidate_daily_users.py` | 历史预览实例的日活检查与修复，保留 18080 布局限制；不是正式实例的修复入口 |
| `cutover_*.py` | 本次迁移的演练、历史合并、恢复、正式切换、真实请求验收及定向清理；依赖阶段证据，不能当成定时维护任务 |

`candidate_daily_users.py repair` 根据现存原始用量明细重算过去的日活。正式库保留了早于原始明细保留边界的历史汇总，因此不能仅把其布局检查改为运行期模式；否则可能清掉有效的旧日活。若以后需要正式修复，须另行限定原始明细完整的日期范围并验证范围之外的数据不变。

合并工具以新实例客户配置为准，用来源映射去重并保留已确认删除的账号／Key 状态。日活等历史汇总不得由残缺的原始明细全量覆盖。清理工具只处理代码中列出的本次迁移对象；其固定对象清单不代表其他历史目录也已清空。

部分验收会产生真实请求、计费或临时修改验收账号额度，必须先了解相应阶段及恢复机制。`cutover_accept_server.py` 的私有 RPC 可能返回认证材料，只能由配套客户端捕获，不能作为普通诊断输出直接展示。

## 本地验证

迁移工具保持 Python 3.6 语法兼容，单测只用标准库和合成账号，不连接服务器，也不依赖本地私有名单：

```sh
python3 -B -m unittest discover -s script/gateway/sub2api-next -p 'test_*.py' -v
```

每日邮件统计由相邻的 [token-usage](../token-usage/README.md) 独立维护。它按个人账号归属汇总美西用量；不要与 Auto/Guard 的 `gateway-usage@us` 独立导出任务混淆。
